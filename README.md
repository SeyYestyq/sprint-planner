# Сервис планирования спринтов

Консольное приложение для планирования задач разработчиков в спринте и контроля овербукинга.
Проект выполнен в рамках Практической работы №2.

## Возможности
- просмотр и поиск разработчиков;
- проверка доступной емкости (capacity);
- проверка текущей загрузки на разработчика;
- назначение задач;
- отмена задач;
- автоматический расчет емкости (правило 80/20);
- генерация имени релиза.

## Структура проекта
- `main.py` – точка запуска;
- `developers.py` – работа с данными разработчиков (коллекции, словари);
- `tasks.py` – работа с задачами (коллекции, списки);
- `storage.py` – сохранение и загрузка данных (контекстные менеджеры, json);
- `utils.py` – вспомогательные функции (безопасный ввод, обработка исключений);
- `data/` – JSON-файлы данных;
- `tests/` – автоматизированные тесты pytest.

## Требования
- Python 3.x;
- pytest;
- flake8.

Установка зависимостей:
```bash
pip install -r requirements.txt
```

## Запуск программы
```bash
python main.py
```

## Запуск тестов
```bash
pytest
```
